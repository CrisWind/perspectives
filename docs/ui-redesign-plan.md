# Perspectives UI 重构任务表

更新时间：2026-11-17

文档状态：用户已确认设计并授权按任务表实施。V1.5 三页落地完成，V1.6 已按最新要求将圆桌页面的导航、侧栏、卡片和操作区统一为首页视觉系统；思想家内容准备仍有外部依赖。

## 已确认方向

- 产品流程拆成三个页面：`首页` → `选择页` → `圆桌会议`。
- 三个页面使用独立路径：`/`、`/choose`、`/roundtable`。
- 首页先解释项目能做什么，再引导用户开始辩论。
- 首页包含项目介绍、MBTI-16 嘉宾介绍、思想家功能介绍、样例辩论播放器和 `Meet Your Council` 入口。
- 选择页收集问题、观点倾向等基础信息，并让用户从 16 位嘉宾中组建辩论阵容。
- 嘉宾浏览使用主卡居中、相邻卡片露出、左右滑动或按钮切换的 card stack；页面同时显示已选区。
- MBTI 嘉宾默认预选 4 位，允许选择 2–4 位；至少选择 2 位才可开始辩论。
- “思想家”是独立的可选席位，加入时不占这 2–4 位 MBTI 嘉宾名额。
- 选择完成后进入圆桌会议；辩题信息、交锋记录、决策卡等文字内容收进左侧栏。
- 当前范围包含首页、选择页及圆桌页面 UI、三页状态与路由；圆桌房间、木桌素材和人物动画继续沿用现有实现。
- 中文桌面端和中文移动端都需要支持。
- 最新视觉方向使用低饱和浅灰/米白莫兰迪背景（如 `#F7F8FA`），承托 16 种角色色；Flat 2.5D 浅弥散阴影、哑光质感及 1%–3% 微噪点。此项替换早期深色底方案。
- 图标、按钮、卡片边角和装饰线条需要与人物形象的气质保持一致。
- 沿用现有角色资料与素材，补齐 16 位角色的统一展示配置。当前前端 `designs` 只覆盖 4 位，不能直接当作完整 16 人数据源。
- 返回选择页时保留问题、观点倾向、已选嘉宾和思想家开关状态。

## 页面规格

### 1. 首页 `/`

目标：让第一次进入的用户在短时间内理解产品，并愿意开始一次辩论。

建议区块顺序：

1. 首屏主张：一句话说明“把纠结交给一组不同视角的人来讨论”。
2. 我们能做什么：用 3 个简短步骤说明输入问题、听取不同观点、得到决策卡。
3. MBTI-16 嘉宾：直接使用素材包“03_性格卡”，16 张卡面向用户沿椭圆轨道轮转；支持暂停、左右切换和点击放大，不设“常驻嘉宾”。
4. 思想家：说明它会怎样补充或挑战常规嘉宾的观点。
5. 样例辩论：首屏“先看一场辩论”及顶部入口点击后弹出首页子页面，内含播放控件和时间线；支持暂停、继续、拖动和重新播放，关闭后停止播放并返回原入口。
6. 开始入口：首屏保留 `Meet Your Council` 进入 `/choose`；不再增加页尾重复入口。

验收条件：

- 用户不填写任何内容也能理解产品用途和三步流程。
- 首页首屏存在清晰的开始入口，样例播放不会遮挡开始入口。
- 16 位角色色在低饱和背景上保持可辨识，装饰不会抢过正文和按钮。
- 桌面端和移动端都能在不依赖悬浮效果的情况下完成浏览和进入选择页。

### 2. 选择页 `/choose`

目标：让用户完成一次有引导的组队和问题输入。

建议布局：

- 顶部：步骤提示 `1 说出问题 → 2 选择嘉宾 → 3 开始圆桌`。
- 左侧或上方：问题表单，包括“你在纠结什么”、观点倾向、补充理由等。
- 主区域：16 人 card stack，主卡居中，两侧露出相邻卡；支持左右箭头、键盘方向键、触摸滑动。
- 卡片操作：点击放大完整原始性格卡，加入/移出阵容、显示当前已选顺序；无“了解性格”按钮或额外介绍。
- 已选区：显示已选头像、数量、推荐提示和移除操作。
- 思想家区：独立开关，展示传习录等思想家的简介和加入后的作用。
- 页面末端操作区：显示当前完成度和 `进入圆桌` 按钮。

交互规则建议：

- 默认预选 4 位互补角色；允许减少到 2–3 位或替换。思想家可额外加入，不计入 MBTI 嘉宾数量。
- 选择状态、表单内容和思想家开关写入前端 session state；返回时恢复。
- MBTI 嘉宾少于 2 位或问题为空时，按钮保持禁用，并在附近解释原因；选择 2–4 位均可继续。
- 推荐把问题、观点倾向、嘉宾阵容、思想家选择汇总在进入按钮附近；是否增加独立的确认弹窗尚未确认，先避免额外步骤。
- 浏览焦点与选中状态分开：滑到一张卡片不会自动加入阵容；“加入/移出”是明确操作，已选区持续可见。
- 性格卡保持原图完整，外部只显示 MBTI 与姓名；点击放大原图，不重复显示介绍或代表性提问。
- 已选区可直接移除嘉宾，无需重新翻阅全部 16 张卡。

验收条件：

- 用户可以不离开当前页面浏览完整 16 人，并清楚知道谁已加入；MBTI 嘉宾数保持在 2–4 位，思想家单独计数。
- card stack 在桌面和移动端都不会被裁切，拖动或按钮切换后焦点和选中状态明确。
- 返回首页或圆桌再回到选择页时，之前填写和选择的内容仍在。
- 表单、卡片和操作区在窄屏下不互相遮挡。

### 3. 圆桌会议 `/roundtable`

接入约定与最新圆桌 UI 范围：

- 接收选择页的问题草稿、嘉宾 ID 列表和思想家 ID；前端字段按现有接口映射为 `dilemma`、`leaning`、`reasons`、可选的 `mbti`，以及 `options.team`、`options.sage`。
- 现有圆桌场景继续作为背景和主要视觉焦点。
- 辩题信息、交锋记录、决策卡等文字内容继续放进左侧导航栏，通过点击打开卡片。
- 具体圆桌场景、角色站位、木色桌面和会议动画另开任务处理。
- V1.6 将页面背景、品牌导航、常驻内容导航、居中弹出卡片、发言字幕和操作按钮统一到首页浅色系统；移动端使用吸顶三项导航，展开卡片时导航不覆盖卡片。
- 侧栏入口保持可见；点击文字项目后，场景变暗、对应卡片进入视口中心，内容过长时在卡片内部滚动。
- 从会议返回时保留选择草稿，后端讨论继续运行；回到会议或刷新时读取快照恢复，不重复创建。

## 视觉系统建议

### 色彩

- 基础背景：浅灰 `#F7F8FA`、米白 `#FFFEFA`；少量鼠尾草、灰紫、暖米色信息卡，降低与人物配色的冲突。
- 角色色：从 16 位人物已有色彩中提取为边框、标签、状态点和按钮图标色。
- 强调色：灰绿色 `#516B60` 统一主要按钮；柔和鼠尾草用于选中状态，文字保持清晰。
- 木色圆桌作为独立场景色，首页和选择页使用更冷、更平静的色调衔接。
- V1.5 已确认并使用该色值；角色色继续沿用原素材，不替换原图配色。
- 正文使用深灰绿 `#303A37`，辅助文字使用 `#626F69`，表单和信息卡靠底色与浅阴影建立层次；正文对比度以 WCAG AA 为验收基线。

### 组件

- 角色卡：原始性格卡完整保留；UI 卡片使用 16–24px 圆角、极浅弥散投影和哑光表面，背景微噪点约 2.2%，避免反光玻璃质感。
- 标题：现代无衬线粗体，卡片外独立显示大号 MBTI 与姓名，优先 Inter/普惠体，本机缺失时回退系统中文字体。
- 信息层级：点击原始性格卡放大，支持按钮、背景及 Escape 关闭，不设性格气泡和重复介绍。
- 导航与步骤：细线、编号、短标签，保持类似角色档案和辩论记录的感觉。
- 图标：使用线性图标和少量角色符号，避免与人物插画争夺注意力。
- 动效：切卡、加入阵容、播放样例使用短距离位移和淡入；尊重 `prefers-reduced-motion`。
- 大头像和人物造型承担主要个性表达；图标统一笔画、圆角和尺度，角色专属符号只作为辅助，不使用混杂的 emoji 作为正式组件图标。
